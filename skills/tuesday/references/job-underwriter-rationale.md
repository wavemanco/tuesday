# Why job-underwriter's rules are shaped as they are

Not required reading: every rule this file explains is stated in `SKILL.md`, or in the reference file `SKILL.md` names at the step that applies it, and nothing here adds to or changes one. It holds the reasons and the measurement history that used to sit beside those rules, so that `SKILL.md` stays short enough to be read whole. Read it before changing a rule, not before following one.

## The skill as a whole

Underwrite an opportunity the way a careful analyst underwrites a risk. A fully qualified candidate can be looking at a badly scoped, misleading, or unacceptable role, which is why fit and opportunity quality are two ledgers. The product is iterative by design: a complete first-pass underwriting from whatever was provided, then short recovery turns that convert "missing from the CV" into what it actually is. That conversion is the promise the whole skill keeps: a missing bullet is four different situations wearing one costume, and only one of them is a real capability problem.

## Step 0 — Intake

Extract before you ask, because asking for what's already derivable wastes the candidate's decision time.

A `pack_feedback` section's gaps and leads are questions to verify, never verified evidence, because they are self-reports made mid-rehearsal.

## Step 1 — First-pass underwriting

The build order matters because each layer feeds the next. The evidence map is the skill's spine; everything downstream reads from it.

The snapshot is delivered first and built last: written from memory of the map rather than from the map, it is where a row added late goes missing and a band goes stale.

No recap anywhere, because the measured recaps restated the snapshot's reading as set claims the snapshot would have had to name ("you clear every must-have"). `references/output-discipline.md` rule 4 gives the general reason.

The gap recovery queue holds no questions because a `Question:` line inside the queue puts questions fourth of nine sections and gives the message two question sites, and both of those are rules this skill already carries.

Every derived statement carries its provenance label so the reader can always see how far the evidence goes.

## Step 2 — Research

Model memory is never a source for company facts, market values, or anything current, because those are exactly the facts that drift.

On the not-attributable rule: borrowing a same-named company's facts is worse than having none.

Budget accounting is one line because a count stated twice can disagree with itself, and then the reader cannot tell which of the two is the mistake.

Target accounting is a table because folding a skip into either of the other labels hides it, and the skip is the case the rule exists for. A wasted search and a correctly-skipped one produce identical prose, so an unfilled row is the only form of this rule a reader or a grader can check. The dossier carries the same table because it renders the same analysis.

Failed attribution is a finding about the opportunity, not only a limit on research.

The closing order puts the dossier offer, the upgrade menu and the questions last because they are calls to action and need to be the last thing the reader acts on.

## Step 3 — Recovery turns

This skill's product *is* iterative recovery, which is why later turns may ask again.

## Step 4 — The dossier offer

`handoff_to_mock_interview` is included so interview prep can start from verified evidence rather than from scratch.

## Output discipline

Three is the budget because this skill's questions are expensive to answer — a recall prompt asks someone to reconstruct a piece of their own history — and because a decidable case earns none at all.

## The n + x rule

Codifying x that keeps earning approval saves reinventing it run after run. The offer is labeled in prose because an `[x]` beside a heading collides with the one notation the reader is relying on to tell evidence from inference.

## Input contract

Non-negotiables earn an orientation question because they are cheap to answer, un-researchable, and can flip the decision. A smaller honest underwriting beats a full-looking fabricated one.

## Guardrails

The reframing audit runs over strategy prose too, because drift migrates to whichever surface is unwatched, and strategy prose is the easiest place for it to pass as insight.

Never a single numeric fit score: an "85% match" hides exactly the hard problems this skill exists to surface.

The approval statement covers the prose advice as well as any table, since imperative phrasing ("your first two sentences should be…") reads as instruction, not proposal.

An employer screening applicants is declined because that is a different job with different obligations.
