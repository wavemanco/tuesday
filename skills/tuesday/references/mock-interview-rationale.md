# Why mock-interview's rules are shaped as they are

Not required reading: every rule this file explains is stated in `SKILL.md`, or in the reference file `SKILL.md` names at the step that applies it, and nothing here adds to or changes one. It holds the reasons that used to sit beside those rules, so that `SKILL.md` stays short enough to be read whole. Read it before changing a rule, not before following one.

## The pack as a whole

Every question carries a rationale because a candidate who understands *why* a question exists answers the follow-up, not just the question.

The pack's credibility rests on its grounding discipline. A fabricated specific — an invented interviewer fact, a made-up company round — can burn the candidate in the live interview, which is worse than no pack at all.

## Step 0 — Intake

Extract before you ask, because asking for something already derivable wastes the candidate's prep time. Files named "passport" are sometimes benign profile summaries, which is why content, not filename, decides.

## Step 1 — Eliciting

A turn that asks and delivers nothing leaves a candidate with an interview on Thursday holding three questions and no preparation, and it breaks the suite's one rule — every skill runs to a complete, useful output from raw inputs. The degradation ladder exists precisely so that a pack can be built without the answers. A pack shipped with no questions attached has quietly decided the assumptions are good enough, which is the user's call and not this skill's.

A message whose only content is an optional offer costs the user a round-trip for nothing.

Why so strict: everything else is either researchable — never ask the user what the web knows — or an enhancer that must not gate generation. Round-and-relationship earns its slot because it's cheap to answer, impossible to research, and reshapes the whole pack; a late-arriving "actually he'll be my peer" forces structural rework rather than an added section. That is the reason to ask it in the first message — not a reason to withhold the pack until it is answered. An open gate earns its slot the same way: only the candidate knows it, and no research can settle it.

## Step 2 — Research

Company values, loop structure, and current strategy come from research or provided docs because these are exactly the facts that drift.

## Step 3 — Synthesis

The reframing audit runs over every guidance cell because every one of them is a sentence the candidate will speak aloud. The build order matters because each layer feeds the next.

The prohibited list is built locally when no dossier arrives because the temptations are identical either way, and both sibling skills maintain such a list — a pack that carries one only when a dossier happens to be present is protected by luck. It is built second because a list written after the banks can only describe what they already did.

## Step 4 — Delivery

The upgrade menu is how enhancers arrive without ever gating on them: make the value of more input visible and let the user pull. The dossier offer carries `pack_feedback` so the objections and gaps rehearsal exposed travel back to the underwriter as leads.

## Step 5 — Iteration

Recompute rather than patch, because a pack that says "hiring manager" in one section and "peer" in another is worse than either.

## Output discipline

The drill and dossier offers sit inside the closing run because they are things the candidate acts on, not commentary on the pack.

## Modes

The drill is scored against the question's own guidance cell, which is why the pack is written before the drill and why a drill on a question whose guidance was generic can only give generic feedback. The pack is preparation; the drill is transfer.

## The n + x rule

Codifying x that keeps earning approval saves reinventing it run after run.

## Input contract

A smaller honest pack beats a full-looking fabricated one.

## Guardrails

"How much of that was actually you" questions are rehearsed because interviewers ask them and candor is scored. An uncertain fact about the interviewer is dropped rather than hedged because the candidate may repeat it live. An employer screening candidates is declined because that is a different job with different obligations: this skill's guidance is deliberately asymmetric coaching.
